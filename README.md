# El león y el ratón

> Un cuento interactivo creado con HTML y CSS.

[![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white)](#tecnologías)
[![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)](#tecnologías)
[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-online-2ea44f?logo=github)](https://jhoamsebastianmunoz.github.io/cuento-2801206/)

Página web estática que narra la fábula **"El león y el ratón"**. El proyecto maqueta el relato con HTML5 para la estructura y CSS3 para el diseño y estilos visuales, e incluye imágenes ilustrativas y un favicon propios.

## Demo

El cuento está publicado con GitHub Pages:

https://jhoamsebastianmunoz.github.io/cuento-2801206/

## Características

- Cuento completo con título, párrafos y moraleja.
- Diseño responsivo mediante `viewport`.
- Imagen ilustrativa y favicon del proyecto.
- Contenido semántico con `header`, `article`, `section` y `footer`.
- Sin dependencias ni proceso de compilación.

## Cómo ejecutarlo

No requiere instalación ni servidor. Solo abre el archivo `index.html` en tu navegador:

1. Clona el repositorio:
   ```bash
   git clone https://github.com/JhoamSebastianMunoz/cuento-2801206.git
   ```
2. Entra a la carpeta del proyecto:
   ```bash
   cd cuento-2801206
   ```
3. Abre `index.html` en tu navegador (doble clic) o usa una extensión como **Live Server**.

> [!TIP]
> Para una mejor experiencia durante el desarrollo, sirve los archivos con una herramienta local como [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) y evita abrir las imágenes con rutas absolutas.
