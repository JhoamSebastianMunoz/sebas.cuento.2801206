# Cuento HTML y CSS

Un cuento interactivo creado con HTML y CSS.

## Descripción

Este proyecto contiene un cuento diseñado con HTML para la estructura y CSS para el diseño y estilo visual.

## Visualización

Para visualizar el cuento, simplemente abre el archivo `index.html` en cualquier navegador web.

## Tecnologías

- HTML5
- CSS3
